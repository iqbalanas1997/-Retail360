# POS UX Skill

1. Read `docs/ui/POS_UX.md`.
2. Keep the main workflow on one screen where practical.
3. Optimize for scan -> quantity -> cart -> payment -> receipt.
4. Prefer keyboard and scanner workflows.
5. Minimize fields, buttons and dialogs.
6. Reuse existing Angular components.
7. Keep cashier UI separate from admin/reporting complexity.
8. Validate usability after implementation with realistic counter scenarios.
