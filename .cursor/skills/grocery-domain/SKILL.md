# Grocery Domain Skill

1. Read `docs/requirements/REQUIREMENTS.md` and `docs/domain/DOMAIN_MODEL.md`.
2. Search `docs/project/MODULE_CATALOG.md` and source code for the concept before adding it.
3. Preserve domain invariants, especially stock traceability and monetary precision.
4. Do not introduce a second representation of an existing business concept.
5. If a requirement is ambiguous, stop and ask rather than inventing behavior.
6. Update domain documentation when a new stable concept is introduced.
